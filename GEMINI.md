# LiveReacting

The `livereacting_*` tools run cloud live streams on LiveReacting's servers: build a project
from a video playlist, multistream it to YouTube, Facebook, Twitch or custom RTMP, schedule it,
change the playlist while live, and read status and analytics.

- Ask the user before you start, stop or schedule a stream, or cancel a schedule. These
  actions go live to real audiences.
- Read-only tools (list, get, status, analytics) need no confirmation.
- Full reference: https://developers.livereacting.com/mcp
